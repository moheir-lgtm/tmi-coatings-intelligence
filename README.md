# TMI Coatings Company Intelligence

This repository publishes the static public-information demonstration workspace for TMI Coatings.

The workspace is an information-architecture demonstration. Financial, operational, valuation, and planning values that are not publicly reported are deterministic synthetic assumptions and are clearly labeled in the application.

## Access

The public, browser-rendered workspace is available at:

https://htmlpreview.github.io/?https://raw.githubusercontent.com/moheir-lgtm/tmi-coatings-intelligence/main/index.html

A browser runtime verification on September 15, 2026 confirmed that the executive header loaded, all 71 integrity checks passed, Reset retained the single `tmi-coatings` instance, no horizontal overflow was present, and the Company Pack export produced a nine-sheet workbook.

GitHub Pages could not be enabled through the available GitHub App token or repository workflow because this account blocks Pages-site creation for that integration. A future owned-domain release can be served through GitHub Pages after it is enabled in the repository settings, or through a Vercel project that is visible to the authenticated Vercel project-management API.

The complete private build and source materials are maintained separately.
